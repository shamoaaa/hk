# 长塘毫米波雷达 - 经产猪配种异常分析

> 本 steering 固化了对长塘配种数据的分析方法和核心发现，供后续分析复用。
> 手动引入：在对话中用 `#配种异常分析` 触发。

## 数据目录结构

根目录：`excel 3.0\长塘\` 下按日期（YYYYMMDD）命名的批次子目录。

- 分析范围：**20260301 及以后**的批次
- 部分批次下还有栋舍子目录（如 `三线2栋`、`四线2栋`、`二线2栋`）
- 栋舍包括：一线配怀3栋、二线配怀2栋、三线配怀2栋、四线配怀2栋

### 每个批次的核心文件

| 文件 | 内容 |
|------|------|
| 人工算法结果汇总.xlsx | **核心文件**。Sheet1=逐猪明细，Sheet2=性能汇总表 |
| 查情配种记录.xlsx | 猪只信息（人工标注真实值），可补充胎次/品种/所属单元 |
| 雷达编号.txt | 本批次参与实验的雷达设备号列表 |
| 超期猪信息.txt | 超期猪的设备号、栏位、耳号 |
| 栏位信息.xlsx / 配种记录.xlsx | 系统导出的原始数据 |

### 文件选择规则（同一目录多个版本时）

- 跳过文件名含「副本」的
- 有「新算法」时跳过「旧算法」
- 有「重跑」版本时优先用「重跑」
- `人工算法结果汇总` 的 active sheet 不一定是 Sheet1，**必须显式取 Sheet1**

### 列结构差异（各批次表头不统一）

需做列名映射，关键别名：
- 设备号 = 「设备号」或「雷达编号」
- 耳号 = 「耳号」或「种猪耳号」
- 配种时间 = 「配种时间」或「配种日期」
- 算法配种时间 = 「算法配种时间」或「算法配种日期」
- 早期批次（如20260301/0304）可能没有「所属单元」「胎次」「是否超期猪」「数据是否异常」列

## 关键定义

- **配种差 = 算法配种时间 − 人工配种时间**（天数，负数=算法早报）
- **正常区间**：经产猪配种差在 **[-1, 0]** 内算正确；超出即为异常
- **误报**：人工无配种时间，算法报了配种
- **未预测**：人工有配种时间，算法没报
- **配种在第几天**：文件夹日期视为「第2天」，第1天=文件夹日期−1天，据此推算实际配种是第几天
- **筛选条件**：仅经产猪（种猪性质=生产种猪，排除后备猪）、排除疾病因素非空、排除数据是否异常非空

## 分析脚本

- 主脚本：`4.0\05_abnormal_breeding.py`
- 输出：`4.0\异常配种明细_经产猪.xlsx`（逐猪明细，含设备号/耳号/算法配种时间/人工配种时间/配种差/配种在第几天/所属单元/胎次/品种/是否超期猪等）
- 分析报告：`4.0\异常配种分析报告.md`（持续更新的发现文档）
- 用 openpyxl 读取，`data_only=True` 时配种差公式缓存可能为空，需自己用日期计算

## 核心发现（截至 20260301-20260525，841头异常猪）

### 错误类型分布

| 类型 | 数量 | 占比 |
|------|------|------|
| 早报2天(-2) | 394 | 47% |
| 误报 | 294 | 35% |
| 早报3天(-3) | 61 | 7% |
| 晚报1天(+1) | 49 | 6% |

### 三个关键结论（控制变量验证过）

1. **早报问题由「配种天数」唯一决定**：固定配种天数后，胎次和超期对配种差无独立影响。
   - 第4天配种→差约-1.8天；第5天→约-2.1天；第6天→约-2.9天
   - 1胎/超期猪整体早报多，仅因它们配种偏晚（第5天为主），非算法对其更差

2. **误报问题中「1胎猪」有独立高风险**：控制批次和栋舍后，1胎误报率仍比多胎高14.8%（41.8% vs 27.0%）。超期无独立影响。

3. **晚报(+1)是早配种猪响应慢**：晚报猪61%在第2天就配了，以2-6胎非超期猪为主。

### 算法优化指导

| 方向 | 需要的特征 | 不需要 |
|------|-----------|--------|
| 延迟确认（解决早报） | 当前天数 | 胎次、超期 |
| 误报过滤（解决误报） | **胎次**、栋舍 | 超期 |
| 早期信号增强（解决晚报） | 当前天数 | 胎次、超期 |

核心建议：算法不要在第2-3天急于输出配种判定，应延迟确认；对1胎猪额外提高误报过滤阈值。

## 分析方法论（重要）

做特征影响分析时**必须用控制变量法**：单看某特征（如超期猪误报率高）可能是混淆变量导致。例如超期猪误报率高，控制配种天数/批次/栋舍后发现其实无独立影响，真正原因是配种时间偏晚。判断一个特征是否真正有用，要在固定其他变量后再对比。
