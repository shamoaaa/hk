# ASR 智能语音识别后端服务 — 项目分析报告

## 1. 项目概述

这是一个面向萤石（EZVIZ）智能设备的**语音识别（ASR）后端服务**，版本 v2.6.0。项目基于海康威视内部的模型服务框架（MS_BE / MS_Manager），以 Python 包的形式部署，运行在 GPU 服务器上（CUDA），对外提供 HTTP 接口。

核心能力：将音频输入转换为文字输出，同时集成了多项语音智能子能力。

## 3. 核心模块详解

### 3.1 FunASR 引擎 (`asr/funasr/`)

项目最大的子模块，是阿里达摩院 FunASR 框架的定制版本。

| 子目录                 | 功能                                                            |
| ------------------- | ------------------------------------------------------------- |
| `bin/`              | 各种推理入口脚本（30+ 个），覆盖离线/流式/VAD/标点等组合                             |
| `models/`           | 模型定义：Paraformer、SeacoParaformer、VAD(FSMN)、Transducer、UniASR 等 |
| `models/encoder/`   | 编码器：Conformer、SANM、FSMN、Data2Vec、MFCCA、RNN 等                  |
| `models/decoder/`   | 解码器：Transformer、SANM、RNN、RNNT、上下文解码器                          |
| `models/frontend/`  | 前端特征提取：默认前端、WAV前端、Kaldifeat前端                                 |
| `models/predictor/` | CIF 预测器（Paraformer 的核心组件）                                     |
| `modules/`          | 通用模块：注意力、Beam Search、嵌入、子采样等                                  |
| `layers/`           | 基础层：STFT、Log-Mel、CMVN、SpecAug、SincConv                        |
| `text/`             | 分词器：Char、SentencePiece、Phoneme、Word                           |
| `datasets/`         | 数据加载与预处理                                                      |
| `tasks/`            | 任务定义：ASR、VAD、标点、说话人验证、说话人日志                                   |
| `train/`            | 训练框架（本项目主要用于推理）                                               |

关键模型：

- **SeacoParaformer** — 非流式 ASR，支持热词（hotword）增强，基于 CIF + Attention 的非自回归模型
- **ParaformerOnline** — 流式 ASR，chunk-based 流式推理
- **E2EVadModel** — 基于 FSMN 的端到端 VAD，支持在线实时检测

### 3.2 WeNet KWS 唤醒词检测 (`asr/wenet/`)

基于 WeNet 框架的 Conformer 模型，用于关键词检测（Keyword Spotting）。

- 使用 CTC prefix beam search 解码
- 硬编码检测唤醒词 **"你好萤石"**（通过字符子集匹配）
- 用于过滤误唤醒场景：当用户通过语音唤醒设备时，验证唤醒词是否正确

### 3.3 声纹验证 (`asr/speakerlab/`)

基于 **ERes2NetV2** 模型的说话人验证模块。

- 提取 80 维 FBank 特征 → 192 维 speaker embedding
- 通过余弦相似度比较唤醒音频与命令音频的说话人是否一致
- 配合响度检测（pyloudnorm），防止"别人唤醒、本人说话"的误触发场景

### 3.4 语义完整性判断 (`asr/semantic_vad/`)

基于 BERT 的文本分类模型，判断当前 ASR 输出的文本是否语义完整。

- 输出一个 0~1 的概率值，映射为 VAD 的 `max_end_sil` 参数（500ms~1300ms）
- 语义越完整 → 静音等待时间越短 → 更快结束识别
- 提供 BiLSTM 和 BERT 两种实现，当前使用 BERT 版本

### 3.5 文本后处理 (`asr/textProcessing/`)

中文文本正则化（TN）和逆文本正则化（ITN）模块，基于 pynini FST。

## 4. 推理流程

### 4.1 非流式推理 (`forward`)

```
音频输入 (base64/url/pcm/wav/aac/opus)
    → 解码为 waveform/bytes
    → SeacoParaformer 离线推理（含 VAD 分段 + 热词增强 + 标点恢复）
    → 返回识别文本
```

### 4.1.1 本项目非流式流程与标准 Paraformer 的关系

本项目的非流式 ASR 流程基于 Paraformer 架构，使用的是其子类变体 SeacoParaformer。核心推理流程完全一致，区别仅在 Decoder 阶段多了 SeACo 热词增强层。

| 阶段 | 标准 Paraformer | 本项目（SeacoParaformer） |
|------|----------------|------------------------|
| 前端特征提取 | FBank + LFR + CMVN | 同 |
| 编码器 | SANM Encoder | 同 |
| CIF 预测器 | 预测 token 数 + 声学嵌入 | 同 |
| 解码器 | Transformer Decoder → `cal_decoder_with_predictor()` → 直接输出 log_softmax | Transformer Decoder + **SeACo 热词偏置层** → `_seaco_decode_with_ASF()` |
| 热词能力 | ContextualParaformer 版本通过 decoder 内部 bias attention 实现 | 通过独立 SeACo decoder 模块实现：LSTM 编码热词 → ASF 动态过滤 Top-50 → SeACo 交叉注意力偏置 → 加权融合（clas_scale 可调） |
| 解码搜索 | BeamSearchPara（CTC-Attention 联合） | 同，额外支持 FST 热词 CTC prefix beam search（本项目未启用） |
| 时间戳 | BiCifParaformer 支持 | 同（本项目未启用） |

简言之：**本项目非流式流程 = Paraformer 骨架 + SeACo 热词增强层**，骨架没变，只是在解码阶段多了一个热词偏置分支。

### 4.2 流式推理 (`stream_init` → `stream_forward` × N)

采用 **2-pass** 策略：

```
第一遍（实时）：
  音频 chunk 到达 → ParaformerOnline 流式推理 → 实时返回中间结果

第二遍（纠正）：
  流结束(is_final) → SeacoParaformer 离线推理整段音频 → 返回最终纠正结果
                      (stage_flag=1 标记纠正完成)
```

流式过程中还穿插了：

1. **VAD 检测** — 实时检测语音起止点，可提前结束识别
2. **语义完整性** — 动态调整 VAD 静音阈值
3. **唤醒词过滤** — 对唤醒音频做 KWS 二次验证
4. **声纹验证** — 比对唤醒人与命令人是否一致

## 8. 非流式 ASR 推理引擎初始化详解

`ezviz_backend.py` 第 45-70 行初始化了非流式 ASR 推理引擎 `self.inference_offline`，它是整个服务最核心的组件。调用的是 `asr_infer_offline`（即 `inference_tp` 函数），该函数内部构建了 `Speech2Text` 推理对象，并返回一个闭包 `_forward` 作为可调用的推理接口。

```python
self.inference_offline = asr_infer_offline(
    dtype="float32",           # 推理精度，使用 float32（未启用半精度）
    maxlenratio=0.0,           # 解码输出最大长度比（0.0 = 不限制）
    minlenratio=0.0,           # 解码输出最小长度比（0.0 = 不限制）
    batch_size=1,              # 单条推理，不做 batch
    beam_size=10,              # Beam Search 宽度为 10
    ngpu=1,                    # 使用 1 块 GPU
    ctc_weight=0.5,            # CTC 与 Attention 解码的权重比（各占 50%）
    lm_weight=0.0,             # 语言模型权重为 0（未使用外部语言模型）
    penalty=0.0,               # 长度惩罚为 0
    log_level="INFO",          # 日志级别
    asr_train_config=...,      # SeacoParaformer 模型配置文件路径
    asr_model_file=...,        # SeacoParaformer 模型权重文件路径
    cmvn_file=...,             # 声学特征归一化文件 (CMVN)
    lm_train_config=None,      # 未使用语言模型
    lm_file=None,              # 未使用语言模型
    streaming=False,           # 非流式模式
    nbest=1,                   # 只取 top-1 结果
    num_workers=0,             # 数据加载不使用多进程
    punc_infer_config=...,     # 标点恢复模型配置（仅加载配置，未加载权重）
    punc_model_file=None,      # 标点模型权重为 None → 实际未启用标点恢复
    is_use_itn=False,          # 未启用逆文本正则化（ITN）
    eable_fst_search=False,    # 未启用 FST 热词搜索
    param_dict=self.param_dict,# 传入热词列表及相关参数
    device="cuda:0"            # 运行在第一块 GPU 上
)
```

### 初始化过程中实际发生了什么

`inference_tp` 函数被调用后，内部依次完成：

1. **构建 Speech2Text 对象** — 加载 SeacoParaformer 模型权重到 GPU，初始化 tokenizer、CMVN 归一化、热词列表
2. **标点恢复模型** — 因为 `punc_model_file=None`，所以 `text2punc` 为 None，标点恢复未启用
3. **ITN 模块** — 因为 `is_use_itn=False`，逆文本正则化未启用
4. **返回闭包 `_forward`** — 赋值给 `self.inference_offline`，后续调用 `self.inference_offline(data, ...)` 即执行推理

### 关键设计意图

- **ctc_weight=0.5**: SeacoParaformer 使用 CTC-Attention 联合解码，CTC 和 Attention 各占一半权重，平衡解码速度与准确率
- **beam_size=10**: 较大的 beam 宽度提升识别准确率，但会增加计算量
- **punc_model_file=None**: 标点恢复在非流式场景下被关闭，可能是因为下游业务不需要标点，或由其他模块处理
- **param_dict 传入热词**: 支持运行时动态更新热词列表，热词通过 SeacoParaformer 的上下文偏置机制（Contextual Biasing）增强识别
- **返回闭包而非对象**: 这种工厂模式将模型加载（重量级）与推理调用（轻量级）分离，模型只加载一次，后续每次推理只执行 `_forward`

## 9. FunASR 开源代码定制修改清单

本项目的 `asr/funasr/` 目录基于开源项目 [FunASR](https://github.com/modelscope/FunASR)（阿里达摩院，约 v0.3.0 版本）fork 后进行了二次开发。以下是与开源版本对比后识别出的所有定制修改。

### 9.1 全局修改：Import 路径重写

所有 `.py` 文件中的 import 路径从开源的 `from funasr.xxx` 全局替换为 `from asr.funasr.xxx`，以适配本项目的包结构（`asr/` 作为顶层包）。

示例：

```python
# 开源原版
from funasr.models.e2e_asr_paraformer import SeacoParaformer

# 本项目修改后
from asr.funasr.models.e2e_asr_paraformer import SeacoParaformer
```

此修改涉及 `asr/funasr/` 下的几乎所有 Python 文件。

#### 各文件 Speech2Text 类对比

项目中共有 8 个独立定义的 `Speech2Text` 类（无继承关系），针对不同模型和场景做了定制：

| 文件                                         | 目标模型                              | 解码方式                                | 热词支持                                                               | 其他特性                                   |
| ------------------------------------------ | --------------------------------- | ----------------------------------- | ------------------------------------------------------------------ | -------------------------------------- |
| `asr_inference.py`                         | Conformer / Transformer           | 自回归 BeamSearch，逐步生成 token           | 无                                                                  | 标准 ESPnet 风格                           |
| `asr_inference_paraformer.py`              | Paraformer / ContextualParaformer | CIF + BeamSearchPara                | 有（按模型类型分支，ContextualParaformer 走 `cal_decoder_with_predictor` 带热词） | 保留 tokenizer；含 `Speech2TextExport` 导出类 |
| `asr_inference_paraformer_punc.py`         | Paraformer                        | 同 paraformer.py                     | 有                                                                  | 推理闭包集成 Text2Punc 标点恢复                  |
| `asr_inference_paraformer_vad_punc.py`     | Paraformer                        | 同 paraformer.py                     | 有                                                                  | 集成 VAD + 标点恢复                          |
| `asr_inference_paraformer_itn_punc.py`     | ContextualParaformer              | CIF + BeamSearchPara                | 有（contextual score）                                                | 集成 ITN + 标点                            |
| `asr_inference_paraformer_itn_punc_fst.py` | ContextualParaformer              | CIF + BeamSearchPara + FST 热词搜索     | 有（ContextGraph + CTC prefix beam search）                           | 在 itn_punc 基础上增加 FST                   |
| **`asr_inference_paraformer_vad_tp.py`**   | **SeacoParaformer**               | **CIF + SeACo 解码 + BeamSearchPara** | **有（SeACo 偏置 + ASF 过滤 + 可选 FST）**                                  | **本项目主力。详见下方**                         |
| `asr_inference_uniasr.py`                  | UniASR                            | SCAMA BeamSearch（BeamSearchScama）   | 无                                                                  | 完全不同的模型架构                              |

#### `asr_inference_paraformer_vad_tp.py` 中 Speech2Text 的独特之处

此文件的 `Speech2Text` 从 `asr_inference_paraformer.py` 的版本 fork 而来，专门为 SeacoParaformer 做了深度定制，是本项目唯一实际使用的版本。与开源原版的关键差异：

1. **解码器调用不同**：不再按模型类型分支判断，直接调用 `_seaco_decode_with_ASF()`（SeacoParaformer 专用），内含 LSTM 热词编码 → ASF Top-50 过滤 → SeACo 偏置融合的完整流程

2. **热词处理重写**：`generate_hotwords_list()` 从开源的"支持文件路径/URL/字符串"三种输入改为"只接受 list 输入"，并增加了：
   
   - 正则过滤：去除 7 位以上纯数字串和设备编码格式的无效热词
   - `seg_dict` 子词分词：利用模型目录下的分词词典做更精确的 token 切分
   - 长度限制：单个热词 ≤ 10 token，总数 ≤ 500 个

3. **去掉了 tokenizer**：注释掉了 `build_tokenizer` 和 `tokens2text`，直接返回 token 列表，文本拼接交给外层 `sentence_postprocess`

4. **新增控制参数**：
   
   - `eable_fst_search`：FST 热词搜索开关（基于 ContextGraph 的 CTC prefix beam search）
   - `eable_time_stamp`：时间戳预测开关
   - `clas_scale_score`：SeACo 热词偏置权重（默认 0.54）
   - `eable_vad`：前端路径选择（`True` 走 `forward_lfr_cmvn` 半程流程，`False` 走 `forward` 完整流程）

### 10.8 本项目实际调用链路

在 31 个文件中，`ezviz_backend.py` 实际只使用了 3 个：

```
ezviz_backend.py
  ├── asr_inference_paraformer_vad_tp.py  →  inference_tp()      → 非流式推理
  │                                       →  vadOnlineInfer()    → 在线 VAD
  └── asr_inference_paraformer_streaming.py → inference_online() → 流式推理
```

其余 28 个文件是从开源 FunASR 保留下来的，在当前部署中未被直接调用。

## 11. 技术栈总结

| 类别     | 技术                                              |
| ------ | ----------------------------------------------- |
| 深度学习框架 | PyTorch 2.0                                     |
| ASR 引擎 | FunASR (Paraformer / SeacoParaformer)           |
| KWS 引擎 | WeNet (Conformer + CTC)                         |
| VAD    | FSMN 端到端 VAD                                    |
| 声纹     | ERes2NetV2                                      |
| 语义判断   | BERT (mini, hidden=192)                         |
| 音频处理   | torchaudio, librosa, pydub, opuslib, pyloudnorm |
| 文本处理   | pynini (FST), sentencepiece                     |
| 服务框架   | MS_Manager / MS_BE (内部框架)                       |
| 配置中心   | Apollo                                          |
