# 环路安全规约（Loop Safety Rules）

本文件始终加载，所有环路和交互均受此约束。

## 急停机制

如果 STATE.md 第一个二级标题是 `## ⚠️ LOOPS PAUSED`：
- 所有环路**立即停止**，不执行任何检查或更新
- 只输出一句："⏸️ 环路已暂停。移除 STATE.md 中的 LOOPS PAUSED 标记以恢复。"

## 禁止区域（Denylist）

以下路径/操作**任何环路都不得自动修改**：
- `.env` / `.env.*` / 任何含密钥的文件
- `**/auth/**` / `**/authentication/**`
- `**/migrations/**`（数据库迁移）
- `package-lock.json` / `uv.lock`（依赖锁文件由专门流程管理）
- `.kiro/hooks/*.json`（环路不能改自己的触发器）

## 副作用限制

- 环路可以**读**任何文件
- 环路可以**写** STATE.md 和 loop-run-log.md
- 环路**不得**自动修改源代码文件（当前为 L1 模式）
- 环路**不得**执行网络请求（HTTP POST/PUT/DELETE）
- 环路**不得**删除任何文件

## 升级给人的条件

遇到以下情况，环路应停止并标记"需人工"：
- 发现安全漏洞（必须人工确认+修复）
- 连续 3 次对同一问题报告无效
- 任何涉及用户数据的操作
- 不确定是否是误报时
