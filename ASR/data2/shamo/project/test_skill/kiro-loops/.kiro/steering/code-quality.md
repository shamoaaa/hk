# 代码质量技能（Code Quality Skill）

当代码文件被编辑时，你具备以下检查能力。

## 必检项（发现即报告）

1. **安全隐患**
   - 硬编码的密钥、密码、token
   - SQL 拼接（未参数化）
   - 未校验的用户输入直接用于文件路径

2. **明确的错误**
   - 类型不匹配（在强类型语言中）
   - 未定义的变量/函数调用
   - 死代码后面还有逻辑（unreachable code）

3. **资源泄漏**
   - 打开了文件/连接但没关闭
   - 裸 `except` / 空 `catch` 吞掉所有异常

## 可选提醒（仅在严重时报告）

- 函数超过 200 行
- 嵌套超过 5 层
- 重复代码块（>20 行完全一致）

## 不报告的

- 代码风格偏好（单引号/双引号、缩进宽度）
- 命名风格争议
- 测试文件中的 mock 写法
- 注释的多少

## 输出规则

- 没问题 → **完全沉默**（不输出任何东西）
- 有问题 → 每个问题一行，含行号
- 不要说"建议考虑..."这种模糊话——要么是问题要么不是
