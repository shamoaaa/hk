# Loop Budget — Kiro 多环路项目

## 每日限额

| 环路 | 最大触发次数/天 | 最大 token/天 | 说明 |
|------|:--------------:|:------------:|------|
| Session Triage | 10 | 50k | 每次新会话触发，一天开10次会话已很多 |
| Code Quality Guard | 100 | 200k | 频繁保存文件，但大部分应静默通过（0 token） |
| Task Verification | 20 | 100k | Spec 任务完成时触发 |

## 总上限

- **每日总 token 上限**：350k
- **单次环路最大输出**：2000 token（防止环路写长文）

## 超限处理

1. 在 STATE.md 顶部标记 `## ⚠️ LOOPS PAUSED`
2. 在 loop-run-log.md 追加超限事件
3. 等待人工确认后移除暂停标记恢复

## 急停（Kill Switch）

- 方式：在 STATE.md 第一个二级标题写 `## ⚠️ LOOPS PAUSED`
- 恢复：人工删除该标题行
- 所有环路在运行前检查此标记（由 loop-safety.md steering 强制）

## 成本估算

| 场景 | 预估 token/天 |
|------|:------------:|
| 轻度开发（3次会话，20次保存，2个任务） | ~30k |
| 正常开发（5次会话，50次保存，5个任务） | ~80k |
| 重度开发（10次会话，100次保存，10个任务） | ~180k |

注：Code Quality Guard 在无问题时静默（0 token），实际消耗远低于理论上限。
