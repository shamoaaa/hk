# Loop Budget — ASR-Evolve

## 每日限额

| 资源 | 上限 | 说明 |
|------|:---:|------|
| GPU 训练次数 | 3 | 每次 ~2-3h，每日最多 9h GPU |
| 数据增强次数 | 5 | 每次 ~40min |
| 推理评估次数 | 10 | 每次 ~10min |
| 连续失败容忍 | 2 | 连续 2 次 CER 无改善 → 暂停 |

## 超限处理

1. 在 STATE.md 标记 `## ⚠️ LOOPS PAUSED`
2. 追加事件到 loop-run-log.md
3. 等待人工分析后恢复

## 急停（Kill Switch）

- 方式：STATE.md 顶部加 `## ⚠️ LOOPS PAUSED`
- 恢复：人工删除该行 + 在 INSIGHTS.md 记录暂停原因和恢复条件

## GPU 花费估算

| 场景 | GPU-hours/天 |
|------|:-----------:|
| 轻度迭代（1 次训练 + 2 次评估） | ~3h |
| 正常迭代（2 次训练 + 5 次评估） | ~5h |
| 密集迭代（3 次训练 + 10 次评估） | ~8h |
